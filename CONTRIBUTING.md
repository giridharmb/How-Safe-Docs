# Contributing to How Safe docs

Thank you for helping make these docs clearer.

- **Typos and small fixes:** open a pull request directly.
- **Larger changes, or changes to legal text** (privacy policy, terms): open an issue first.
- **Writing style:** plain language, short sentences, second person ("you"). Avoid alarmist wording, and never stigmatise neighbourhoods or groups.
- **Release notes:** use `templates/release-notes-template.md`.
- **Previewing locally:** `bundle exec jekyll serve`, or just push to a branch and check the GitHub Pages preview.
